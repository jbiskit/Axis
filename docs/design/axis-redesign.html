Axis redesign, round 1

Four boards for the shell, the one page pattern every surface shares, a review page in that same pattern, and a tenant home. A component sheet closes the set. Figures Axis has actually read from contoso are real: Secure Score, MFA 7 of 25, profile names, the licence and the single device. App counts, most user rows, statuses and the activity list are illustrative.

One shellModules sit in the titlebar. A single sidebar replaces the icon rail plus context panel.
One page patternFilters, then a table with bulk actions. The inspector appears only when you select something, so nothing sits empty. Intune, Entra, Purview and Defender all work the same way.
Platform is a filterWindows, macOS, iOS and Android are chips on the page, not branches you drill through in the nav.
State before detailStatus dots, severity stripes and counts show what needs attention before you read a word.
